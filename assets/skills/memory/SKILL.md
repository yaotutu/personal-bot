# 长期记忆 (Memory)

本技能允许你显式地管理长期记忆，将用户的重要信息保存下来，以便在未来的对话中回忆。

## 触发时机
- 用户说：“记住我喜欢喝美式咖啡”、“忘掉我之前告诉你的地址”、“把我老婆的生日记下来”。

## 可用工具
### `memory`
用于管理长期记忆条目。

**参数说明：**
- `action`: 操作类型，可选 `add`（添加）、`delete`（删除）、`search`（搜索）。
- `content`: （添加时必填）要记住的具体信息，尽量简洁明了。
- `query`: （搜索或删除时必填）用于查找记忆的关键词。

## 调用示例
用户：“记住我对花生过敏”
调用工具：`memory({ action: "add", content: "用户对花生过敏" })`
