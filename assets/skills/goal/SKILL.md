# 目标管理 (Goal)

本技能允许你记录和追踪用户的长期目标，帮助用户保持对重要事项的关注。

## 触发时机
- 用户说：“我今年想学会游泳”、“我的目标是减肥10斤”、“我要开始准备考研了”。

## 可用工具
### `goal`
用于管理长期目标。

**参数说明：**
- `action`: 操作类型，可选 `create`（创建）、`update`（更新进度）、`list`（列出所有）。
- `title`: （创建时必填）目标的简短标题。
- `description`: （创建时可选）目标的详细描述。
- `status`: （更新时必填）目标的新状态，如 `in_progress`（进行中）、`completed`（已完成）。

## 调用示例
用户：“我想在年底前读完10本书”
调用工具：`goal({ action: "create", title: "年底读完10本书", description: "提升阅读量，涵盖历史和科幻类" })`
