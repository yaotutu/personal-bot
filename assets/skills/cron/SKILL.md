# 定时任务与提醒 (Cron)

本技能允许你为用户创建、查看和取消定时任务；当前只支持一次性任务和每日任务，不支持每周或按 cron 表达式调度。

## 触发时机
- 用户说：“10分钟后提醒我喝水”、“每天早上8点叫我起床”。
- 用户要求“每周”“每月”或通用 cron 表达式时，明确说明当前不支持；不要注册错误的每日任务。

## 可用工具
### `schedule`
用于管理定时任务。

**参数说明：**
- `action`: 操作类型，可选 `create`（创建）、`list`（列出所有）、`cancel`（取消）。
- `prompt`: （所有 action 都必填；`list`/`cancel` 传占位文本）创建时是提醒或任务的自包含内容，例如“喝水”。
- `at`: （所有 action 都必填；`list`/`cancel` 传占位文本）一次性任务用带时区的 ISO 8601 时间；每日任务用 `HH:mm`（00:00 至 23:59）。
- `daily`: （创建时可选）`true` 表示按 `at` 的每日时间重复执行。
- `jobId`: （取消时必填）要取消的任务 ID，先由 `list` 查询。

## 调用示例
用户：“2026-10-29 18:30（上海时间）提醒我关火”
调用工具：`schedule({ action: "create", prompt: "关火", at: "2026-10-29T18:30:00+08:00" })`

用户：“每天早上8点叫我起床”
调用工具：`schedule({ action: "create", prompt: "起床", at: "08:00", daily: true })`
