# Agent 协作指南

本文是 pi-muse 工作区所有主/子 Agent 开发工作的必读协作规范，负责任务单、执行入口、失败语义、日志边界和交付验收。全局安全、数据、进程、提交和真实测试底线见[根规则](../../AGENTS.md)；模型选择见[模型分工](../../model-policy.md)。本文不维护业务架构、API 或测试细节。

## 职责分工

- 主 Agent 负责需求澄清、产品与架构取舍、安全与协议决策、任务拆分、依赖管理、关键 diff 审查、集成验收、进程协调、项目地图更新和本地提交汇报。
- 执行者负责派单范围内的调查、实现、配套回归测试、局部文档和聚焦修正；只返回结论、关键文件位置、实际验证结果、风险与未验证项，不回灌完整日志。
- 主 Agent 不把最终责任转交给“子经理”，也不先完成大块实现再让执行者重做。用户明确要求直接执行、禁止委派或限定写集时，所有执行者按该指令执行，不得递归委派。
- 委派不可用时如实报告；主 Agent 只继续职责内的协调和小事，不因此接管大块实现。
- 按业务链路拆任务，不固定划分服务端/移动端团队。跨端任务先由主 Agent 确定契约、失败语义和依赖；仅互不依赖且写集不重叠的任务可并行，默认并发 1、最多 2。共享契约或共享文件串行修改。

## 任务单

每项委派在派单正文包含以下字段；小任务可在同一段落紧凑表达，不为逐任务新增文档或状态表。

```text
目标：用户可观察的变化
范围/所有权：允许修改的文件/模块、共享文件协调方式
非目标：本次明确不做的事
依据/依赖：契约、必读文档、已确定设计与前置任务
约束：权限、数据、进程、发布、不可自动重试等边界
验收：可观察行为、异常与迟到场景、验证命令和环境
交付：修改位置、实际验证结果、风险与未验证项
```

- 验收必须描述实际行为与版本范围，例如“旧响应不得污染新空间”“结果未明不能重发”“读取失败不能显示为空列表”；不能只写“功能正常”或“测试通过”。
- 派单同时传递真实后端与真实外部模型要求、费用长期授权、隔离数据边界和共享工作区提醒。执行者发现跨范围、协议、安全或权限问题时停止并携证据返回，不自行扩大写集。

## 执行入口

- 当前用户决定暂不修复原生 subagent，临时默认使用本机 `codex exec` 启动、准确会话 ID 的 `resume` 续派。未获新的明确要求前，不启用原生探针、修改全局配置或要求用户反复重建会话。
- 新派单与正常续派使用任务级 `--disable multi_agent` 阻止执行者继续委派；不用 `--last` 误接其他任务，不改全局配置、不绕过审批或扩大权限。CLI 退出成功不等于原生 subagent 已修复。
- 若未来获准使用内置启动/续派工具，其参数中 `message` 与 `items` 二选一，未使用字段完全省略，不能填空数组或空字符串；可选参数同样按实际支持省略。参数校验失败不代表执行者已启动。本条不适用于 `codex exec` 参数。
- 记录执行入口、请求模型、准确会话 ID、退出码、关键 diff 与验证结果。结果未明时先检查执行状态与文件 diff，再用准确 ID 续派；不能确认前一个执行者结束并释放写集时，不启动接替写入者。

## 失败与日志

- 区分调用失败、执行失败和验收失败。调用未启动不得记为执行失败；执行者完成也不等于主 Agent 验收通过。不反复重发相同无效参数，不盲目多层重试或转包。
- 只读探测可安全重试一次；写任务超时、断线或结果未明时，先核对状态与 diff，不得直接重放整张任务单。模型路由失败、限流和不支持参数的处理见[模型分工](../../model-policy.md)。
- 禁止整体输出 `env`、`printenv`、凭据配置或开发工具密钥。确需核对环境时，只检查已知变量存在性或非敏感状态；socket/IPC 被沙箱拒绝或权限阻塞时停止相应探测并返回主 Agent，不倾倒环境或扩大权限。
- 不把密钥、token、用户已有会话内容、用户实例数据或完整日志写入交付、文档、项目地图或验收记录。隔离测试数据与必要错误证据先脱敏，只保留验收和定位所需内容。

## 闭环

1. 需求与写集 → 必要调查与契约确认 → 分派实现及回归测试 → 主 Agent 审查 diff → 双端集成验收 → 模块内整理与必要复验 → 更新项目地图 → 对应子仓库本地提交并汇报。
2. 主 Agent 验收时检查关键实现、实际命令结果、真实验收证据和未验范围，不以执行者结论代替独立核查。自动化、真实接口、真实模型与原生运行分别记录，历史通过不算本次通过。
3. 文档-only 变更只检查差异、引用、命名与规则一致性；涉及手册构建、导航或用户可见行为时另按[Agent 文档编写指南](agent-documentation-guide.md)完成对应验证。
