# Activity 执行活动：业务规则讨论

记录日期：2026-10-18。

**状态：业务规则、接口及本轮生命周期方案已确认并授权在 `feat/activity-records` 独立 worktree 实施。** 本文保留决策依据，不是第二份接口契约；当前字段与接入规则以运行时 `/docs`、`/openapi.json` 为准。带版本与范围的验收记录见 `../archive/2026-10-19-activity-e2e-acceptance.md`。

## 已确认：什么进入活动记录

- 动态用于跟踪用户交办的一项工作，不是聊天历史的副本，不因每次用户发消息就创建记录。
- 由当前主 Agent 理解完整对话，决定正常交流还是开始推进一项工作；不是额外运行一个分类模型，也不是后端解析回复来猜。
- 不穷举工作类型，不以关键词、耗时、工具次数或是否调用 subagent 机械分类。
- pi 不提供“普通对话”自动标记。没有登记仅表示没有活动记录，不能证明模型一定正确分类，也可能漏调；不承诺零误判。

## 已确认：登记工具的职责与规则

工具定名为 `activity`，动作包括 `start` / `resume` / `update` / `wait` / `complete`；参数由工具 schema 约束，以下为必须表达给 Agent 的语义规则：

> 登记一项正在为用户执行的工作，让用户能跟踪它的进展和结果。登记本身不执行工作、不启动后台任务、不调用子代理，也不扩大权限。
>
> 当用户已经把一个目标交给你完成，而你决定开始实际推进时，先登记活动，说明要做什么、完成后交付什么，再继续执行。
>
> 普通交流、知识解释、澄清问题、需求讨论、方案审阅或简单查询不登记。不要为了调用了某个工具就登记；内部准备、读取记忆、每次工具调用或每个子代理不各自登记。相同工作已经登记时，更新原活动，不重复创建。

用于校准而非穷举的例子：

- “研究这个方案是否合理，先讨论，不要实施”：讨论，不登记。
- “方案确定了，现在去实施并验证”：开始工作，登记。
- “调研 Pi 生态圈，整理结论给我”：交办工作，登记。
- “刚才说的 Pi 生态圈是什么意思”：解释，不登记。

是否登记与是否使用 subagent 分开：主 Agent 可以自己执行，也可以委派；不恢复已经移除的 delegate_task 或业务 worker 队列。

## 已确认：什么时候完成

- 一条活动覆盖整项交办目标。搜索网页、阅读资料、处理文件、编辑成果、等待审批及调用子代理，均是所属活动的执行过程，不分别创建业务活动。
- 达成目标所需的必要步骤全部完成、结果已交付后，才由主 Agent 明确登记完成。
- 单个工具结束、子代理返回或一轮模型回复结束，都不能自动等同于活动完成。
- 例如“调研 X 并整理文档”：收集资料、阅读、整理和要求的文档操作完成，并交付结果后才算完成。PDF 只是用户举例，不代表已经新增 PDF 工具或其他执行能力。

## 已确认：详情分为概览和逐步明细

- 用户明确要求两层展示，不能把详情也只做成关键进展摘要。
- **概览：** 工作目标、当前状态、关键进展、最终结果或交付成果，以及来源会话。
- **逐步明细：** 把实际执行的每一步按时序列出；各步包含执行状态、时间和结果，失败、拒绝、取消如实保留。工具操作、子代理及其步骤、审批与实际文件提交均归属原活动，不另建活动。
- 步骤来自真实执行事件，不让模型事后编造已执行过程；不暴露模型内部思维、凭据或未脱敏日志。步骤可追溯不等于自动开放原始工具参数与全文结果，具体载荷和安全投影在接口设计时明确。
- PDF等是说明多步工作的例子，不因记录方案自动新增当前没有的执行工具。

## 后续确认与本轮边界

- 查询接口采用 `GET /api/activities` 与 `GET /api/activities/:id`，列表使用游标分页，不设七天过滤或自动清理；详情同时返回概览与真实步骤。
- 用户明确选择：停止后要求继续时沿用原活动，保留之前的停止步骤；删除来源会话时活动随历史删除，共享文件不删除。
- 完成声明须等当前轮次成功收尾并交付后生效；未声明完成则待继续，明确阻塞则等待用户。崩溃遗留步骤只读投影为 interrupted，不自动重跑，无法确定的结束时刻保留 null。
- 概览与步骤写入来源 thread 唯一 pi JSONL 的 custom entries，不另建历史权威或后台队列。
- 全局 SSE 对接不属于本轮范围，仍待单独讨论；不新增 Activity SSE 事件。
- 用户授权本轮隔离真实模型验收。费用调用与页面、模拟 provider 进程 E2E 必须分别报告，不能相互替代。

OpenMuse 仅参考其“系统指令与工具描述引导当前模型自主选择”的机制；其 durable 委派队列、用户直接创建后台任务等产品实现不照搬。
