# 长期记忆与 Dream

本页说明手机客户端中的全局长期记忆浏览、搜索、增删改，以及 Dream 如何把聊天内容整理为资料、空间规则或记忆。入口和限制按当前移动端与服务端源码核对；源码能力不自动等于某个已发布 APK，实际界面以你安装的 Release 为准。

## 前提 {#prerequisites}

- 已按[快速上手](getting-started.md#connect-mobile-client)连接服务端，并且设置页中的「长期记忆」和「Dream 记忆整理」可用。
- 浏览、搜索和管理长期记忆只需要服务端可访问；Dream 整理轮还会真实调用服务端配置的外部模型，模型未配置或不可用时会失败。
- 长期记忆、SOUL/USER 资料是全局内容；聊天记录、空间规则和 Dream 的整理游标按空间独立。

## 管理长期记忆 {#manage-long-term-memories}

1. 进入底部「设置」→「助手记忆」→「长期记忆」。页面打开后显示全部记忆；读取中会提示正在等待服务端记忆。
2. 查看「全部记忆」时最多显示 500 条，按更新时间从新到旧排列。每条显示正文、来源和更新时间。
3. 在「搜索记忆关键词」框输入关键词后点击「搜索」或键盘搜索键。搜索使用忽略大小写的子串匹配，最多返回 10 条最近更新的匹配记忆；关键词去除首尾空白后不能超过 200 字符。
4. 点击「全部」回到完整列表；点击「刷新」重新读取当前视图。
5. 点击「新增记忆」，输入 1–2000 字符的正文后选择「保存记忆」。成功后显示「记忆已新增」并回到列表；通过手机界面新增的来源标记为 `Mobile UI`。
6. 点击某条记忆的「编辑」，修改正文后保存。成功后显示「记忆已更新」，更新时间变化。
7. 点击「删除」后，页面显示完整待删正文。确认删除会影响全部空间，且不会删除聊天历史；成功后显示「记忆已删除」。

删除长期记忆不可撤销。记忆总数达到 500 条后，服务端会拒绝新增；请先编辑合并或删除旧条目。不要把密码、API key、token 或其他秘密保存为记忆。

读取失败时页面保留最后观测到的内容并提示最新状态待核对；此时不能修改。写入中断或超时可能已经生效，页面会锁定修改并提示先读取「全部记忆」核对。核对后点击「已核对，解除提交锁定」，再决定是否发起新操作；客户端不会自动重试写入。

## 记忆与资料边界 {#memory-and-profile-boundaries}

| 内容 | 范围 | 进入模型的时机 |
| --- | --- | --- |
| 长期记忆 | 全局，全部空间共用 | 不逐轮携带；模型认为可能相关时按关键词检索 |
| USER 用户资料 | 全局，全部空间共用 | 下一轮开始作为用户资料注入 |
| SOUL 助手人设 | 全局，全部空间共用 | 下一轮开始作为助手人设注入 |
| 助手名字与语气 | 全局，全部空间共用 | 保存后从下一轮对话生效 |
| 长期目标 | 全局，全部空间共用 | 不自动进入普通聊天；启用 goal 技能的空间可按需查询和管理 |
| 技能资产 | 文件全局一份 | 只有当前空间启用的技能会在下一轮加载；空间保存的是开关覆盖 |
| 共享工作区 | 全局 | 必须通过 `shared/...` 显式访问，不随私有工作区搜索出现 |
| 信息偏好 notes | 每个空间独立 | 仅由该空间的信息后台读取；Dream 不把它改写成另一套偏好 |
| 聊天记录 | 每个空间独立 | 由所属空间的会话使用；重置或删除空间会清除 |
| 空间规则 | 每个空间独立 | 保存后从下一轮对话生效 |

在启用了记忆技能的空间，可以明确要求助手新增、修改或忘记某条事实；是否执行以实际工具结果为准，并可在本页刷新、搜索核对。已启用 Dream 的空间还会按配置另行整理聊天。消息反馈不会自动进入普通聊天上下文，也不用于偏好训练；空间显式开启信息后台时，该后台决策轮可读取本空间当前反馈例证。SOUL/USER 的填写与保存见[资料与设置](profile-and-settings.md#assistant-and-user-profile)。

## 配置 Dream {#configure-dream}

1. 进入底部「设置」→「助手记忆」→「Dream 记忆整理」。页面显示全局概览、全局提示词、空间选择、当前空间设置、最近整理和待决建议。
2. 「全局整理提示词」是全部空间共享的基础配置，最多 20000 字符。留空并保存表示清空自定义内容，改用内置默认提示词；可点击「查看内置默认提示词」核对默认行为。
3. 修改后点击「保存全局提示词」。成功后显示「全局 Dream 提示词已保存」；「取消修改」会回到最后一次成功读取的值，「清空草稿」只清空输入框，不会在保存前生效。
4. 在「选择整理空间」中点击已有空间。若当前空间有未保存的周期或补充提示词草稿，切换前需要确认丢弃该空间草稿；全局草稿会保留。
5. 在「当前空间设置」中配置：
   - 「参加定期整理」：主空间默认开启，其他空间默认关闭。关闭后仍可手动整理。
   - 「继承全局提示词」：开启时使用全局提示词加本空间补充；关闭时以本空间补充提示词为准，若本空间补充为空，仍回落到全局有效提示词或内置默认提示词。
   - 「本空间补充提示词」：最多 20000 字符，只补充当前空间；保存空串表示清空补充。
6. 点击「保存空间设置」。成功后显示「空间 Dream 设置已保存」。

Dream 的固定安全规则始终生效，不能被全局或空间提示词覆盖：整理轮只能提交结构化笔记建议，没有文件读写、联网或委托工具；外部内容不能当作指令；不能保存凭据，不能把助手猜测当作用户事实，也不能修改权限、工具、模型或配置。「本空间用途」在 Dream 页面只读。

固定规则还说明数据作用域：USER、SOUL 和长期记忆是全局目标；只有由本空间用途产生的筛选规则、兴趣范围、敏感度要求或格式要求才写入本空间规则。信息后台的偏好 notes 继续由原有信息入口维护，Dream 不暗中改写。某个目标全局可用不代表它适合所有场景；新事实是否跨空间稳定不明确时应进入待决建议。这些是模型分类指引，服务端强制工具与审批边界，但不能保证自动判断每个事实的真实作用域；自动写入后可在相关页面检查，待决建议仍由人工确认。

后台固定每 2 小时检查一次已开启周期整理的空间；检查时间不等于保证完成时间，正在对话或已有 Dream 整理的空间会被跳过。关闭某个空间的周期整理只影响后续自动检查，不会撤销已写入内容。

## 手动整理 {#run-dream-manually}

1. 在 Dream 页面选择空间，先分别保存或取消全局与空间的未保存修改。存在草稿时「立即整理当前空间」不可用，草稿不会用于本次模型执行。
2. 点击「立即整理当前空间」。请求会同步等待真实模型完成，客户端最长等待 300 秒；期间可以继续使用应用，但不要重复点击。
3. 查看成功状态：
   - 「已完成」表示整轮成功，本轮处理的消息游标推进；如无新消息，会记录处理 0 条且无实际变更。
   - 「部分完成」表示部分目标或待决建议已写入，但存在失败；游标不推进，下次会从原位置重读。
   - 「失败」表示本轮结束状态已正常记录，且没有产生写入；游标不推进。服务重启造成的中断按下方说明单独核对。
4. 查看「处理消息」和「实际变更」判断影响范围；失败或部分完成时页面会显示服务端受控错误说明。

Dream 不提供停止操作。离开页面、退到后台、关闭应用或客户端请求超时，只表示手机停止等待，不代表远端整理已停止或失败；回来后先点击「刷新」核对最近整理状态，未确认前不要直接重跑。服务重启会把中断时仍显示运行中的整理记录改为失败；这个失败标记不代表此前写入不存在，也不会回滚已完成的写入。先回读 USER/SOUL、空间规则、长期记忆和待决建议，确认后再整理，不要仅凭失败状态直接重跑。

手动整理会从上次游标之后的新消息提取，并附带此前的重叠上下文用于理解；模型被要求只从新消息提取。主空间可能直接写入全局 USER/SOUL；非主空间提出的全局 USER/SOUL 建议会进入待决列表。空间规则写入要求该空间已有用途，并且只应收纳本空间用途导致的偏好。对既有长期记忆的修改或删除必须引用确切 ID；如果模型不确定是否该改，应不提出该条，而不是把它转成待决新增。并发修改的目标会被跳过覆盖并反映为失败或部分完成。

## 处理待决建议 {#resolve-dream-suggestions}

1. 在「待决建议」中阅读完整正文、提出时间、原因和建议归属。原因可能显示为「归属不明确」「来自单一会话，但建议写入全局资料」或「空间尚未设置用途」。
2. 在「实际应用到」中选择 `USER`、`SOUL`、`规则` 或 `记忆`，不必保留模型建议的目标。
3. 点击「应用到所选目标」，核对确认框中的完整正文和目标后点击「确认应用」。
4. 如不想写入，点击「忽略建议」并确认忽略。

实际影响：

- `USER`：追加到全局用户资料，影响全部空间。
- `SOUL`：追加到全局助手人设，影响全部空间。
- `规则`：追加到当前空间规则，只影响当前空间；超过空间规则长度限制时会失败。
- `记忆`：始终新增一条全局长期记忆，占用 500 条上限；该操作不用于确认编辑或删除，不确定的既有记忆编辑/删除应在整理建议阶段被省略。
- 「忽略」只把这条建议从待决列表移除，不写入任何目标；聊天记录本身不会被删除。

应用成功后该条待决建议立即从列表移除。写入是追加或新增，不会自动改写成摘要，也不会先展示差异编辑器；应用前必须人工确认完整正文。操作结果未明时，先刷新核对列表和目标内容，再决定是否重新操作；客户端不会自动重试。

## 重置与删除影响 {#dream-reset-and-delete}

- 「重置当前会话」会清空该空间的聊天历史、消息反馈、Dream 整理游标、最近整理结果和待决建议，并保留该空间的 Dream 开关、继承设置、补充提示词、空间规则和工作区文件。Dream 已写入的 USER/SOUL、全局记忆或此前空间规则不会被回滚。
- 删除空间会同时删除该空间的聊天历史、消息反馈、Dream 配置、整理状态、待决建议、空间规则和绑定任务。已写入的全局 USER/SOUL/长期记忆不会被删除。
- 详细步骤、确认和不可恢复范围见[对话与空间](conversations-and-spaces.md#reset-and-delete-spaces)。

## 限制与故障 {#limits-and-failures}

- Dream 概览读取失败或状态待核对时，不能保存、整理或处理待决建议；先刷新。
- 同一时刻只有一个 Dream 整理轮。当前空间正在聊天、空间不存在或已有整理运行时，手动整理会被拒绝。
- 模型未配置、请求失败、无效建议、并发修改、记忆达到上限或服务关闭都会导致失败或部分完成；已写入的部分不会自动回滚。
- 待决建议列表最多保留 50 条去重后的建议。处理前要核对完整正文，特别是改选到 USER、SOUL 或记忆这类全局目标时。
- Dream 的作用域分类依赖模型理解提示词；服务端能强制工具、权限、ID 和主/非主空间写入规则，不能凭代码证明每个事实在现实生活中确实跨空间稳定。
- Dream 写入的资料从后续模型轮开始生效，不会修改已生成的聊天记录。
