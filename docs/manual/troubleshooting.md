# 常见问题

本页从可见现象出发给出低风险检查。写操作结果未明时，先核对服务端状态，不要自动重发。当前操作入口以[快速上手](getting-started.md)和两篇日常操作指南为准。

## 手机连不上服务端 {#phone-cannot-connect-to-server}

1. 在服务端本机访问 `/api/health`。若失败，先确认进程和端口。
2. 核对手机「服务器连接」中的地址是服务端基础地址，不带 `/api` 或 `/docs`。
3. 局域网使用时确认填写电脑真实 IP，且防火墙允许 `17890` 入站。
4. 若状态为「暂时不可用」，在「服务器连接」中点击「重试连接」。

手机上的 `localhost` 指向手机自身，不能用于连接电脑服务。

## AccessKey 被拒绝 {#access-key-rejected}

客户端「访问密钥」应填写 `server.accessKey`，不是 `model.apiKey`。核对该服务端实际读取的配置文件；修改或清除 AccessKey 后，旧 Token 会失效，需要在原地址重新认证。

不要把任何密钥粘贴到公开日志、截图或问题报告。

## 测试通过但连接未保存 {#test-passed-but-not-saved}

「测试通过，尚未保存」表示地址和密钥可用，但配置还没有写入手机。必须继续点击「连接服务器」或「保存新地址」。更换地址前出现的确认框会清理本机旧业务缓存和旧凭据，不会删除远端数据。

## 模型没有回复 {#no-model-reply}

检查 `model.baseUrl`、`model.id` 和 `model.apiKey` 是否属于同一个可用模型服务，并查看服务端返回的受控错误。模型请求失败后不会自动重试；若上一轮可能已经执行写入或其他工具，先核对实际结果，再决定是否重新发起。

若聊天页显示「重新同步」，点击它恢复权威历史和运行状态；不要只凭最后一次流式画面判断成功或失败。

## 停止或断线后状态不明 {#stop-or-disconnect-state-unknown}

停止会取消当前聊天运行和未决审批，但已完成的工具操作不会回滚。停止、切走聊天视图或断线后，客户端可能显示「执行结果待同步」或「消息保存状态待确认」。

一般聊天停止、断线或消息保存状态未明时，点「重新同步」，等历史和状态同步完成再继续发送。「核对重置结果」只在重置待确认时出现，不要把它当成普通同步入口。仍无法确认时，查看[对话与空间](conversations-and-spaces.md#send-and-stop-conversations)；涉及文件写入时先回读目标文件。

## 附件被拒绝 {#attachment-rejected}

常见原因是超过 4 个附件、总大小超过 8 MiB、文本附件合计超过 100,000 字节、文件为空、图片字节与声明格式不符，或文本不是有效 UTF-8。系统选择器只能读取本机返回的本地文件。

完整类型和大小限制见[附件、文件与审批](files-and-approvals.md#send-attachments)。被拒绝的附件不会加入草稿；修正文件后重新选择，不需要重发整段对话。

## 文件修改没有生效 {#file-modification-did-not-take-effect}

模型 `write` 和 `edit` 每次都需要独立人工审批。拒绝、超过有效期、等待期间文件变化、运行取消、审批详情未读取或执行失败都会阻止该次提交；已批准也不等于执行成功。查看「审批」中的完整预览和执行回执。

手动工作区编辑则发生在「工作区」页的保存确认中，不生成模型审批记录。结果未明时先按[附件、文件与审批](files-and-approvals.md#approve-model-file-writes)回读核对，不自动重发写操作。

## 重置或删除结果未明 {#reset-or-delete-result-unknown}

重置和删除都是破坏性请求，网络错误不代表服务端未执行。客户端会保留待确认提示，不会自动重试。先刷新空间列表并核对新会话 ID 或空间是否消失，再继续操作。

重置会清空聊天历史并作废未决审批；删除空间会级联删除该空间历史、工作区文件、规则、技能、任务和监控，均不可恢复。完整影响见[对话与空间](conversations-and-spaces.md#reset-and-delete-spaces)。
