# 长期目标

本页说明如何在移动端创建、筛选、更新和删除长期目标，以及目标如何进入模型上下文。内容按当前服务端与移动端源码核对；源码核对不等于本轮实际业务运行或发布 APK 实测，已安装 Release 的可用功能以该版本界面和发布说明为准。

## 用途与范围 {#purpose-and-scope}

长期目标是全局记录，不属于任何空间。进行中的目标会在每一轮对话前重新读取并注入所有空间的系统提示，帮助模型在规划和回答时参考目标、进度和下一个未完成里程碑。

目标本身不执行计划、不创建定时任务、不监控网页，也不会自动调用工具。需要实际执行时，仍在聊天中明确委托模型，或按[定时任务、网页监控与活动历史](tasks-and-monitors.md)单独创建任务与监控。

## 前提 {#prerequisites}

- 手机已按[快速上手](getting-started.md#connect-mobile-client)连接真实服务端。
- 目标页面通过底部「目标」页进入；查看、创建、更新状态、勾选里程碑和删除不依赖当前空间。
- 若希望通过聊天让模型创建、列出、勾选或改目标状态，当前空间的 `goal` 技能需保持开启；默认内置技能开启。

## 查看与筛选目标 {#view-and-filter-goals}

1. 点击底部「目标」页。
2. 用「全部」「进行中」「已暂停」「已完成」「已归档」筛选状态。
3. 在「排序」中选择「更新时间」或「创建时间」，再点击「升序」或「降序」。默认按更新时间从新到旧排列。
4. 查看目标卡片中的分类、描述、里程碑完成数、每个里程碑完成时间、创建时间和更新时间。

当前页面没有搜索框和分类筛选。列表读取失败时保留上次内容并显示错误，不会显示为空列表；提示旧数据时先刷新成功再操作。

## 新建目标 {#create-goals}

1. 点击底部「目标」页的「新建」。
2. 填写「标题」。标题必填，不能只有空白，最多 160 字符。
3. 按需填写「描述」，最多 2,000 字符。
4. 按需填写「分类」，最多 40 字符；留空时服务端保存为 `general`。
5. 如需初始里程碑，在「初始里程碑」中每行输入一个标题；每个标题最多 160 字符，最多 30 项。
6. 点击「保存目标」。成功后表单关闭，新目标显示为「进行中」。

保存前可点击「取消新建目标」丢弃表单。标题为空时保存按钮不可用；若提交中断或结果未明，页面会保留表单并锁定，不会自动重发。

## 更新状态与里程碑 {#update-status-and-milestones}

1. 在目标卡片的「状态」行点击「进行中」「已暂停」「已完成」或「已归档」。
2. 勾选或取消里程碑时，直接点击该里程碑行。已完成里程碑会显示完成时间；取消后完成时间被清除。
3. 修改后核对列表中的状态、里程碑计数和更新时间。

把目标设为「已完成」会自动勾选全部未完成里程碑；重新改为「进行中」或「已暂停」不会回退这些勾选记录。反过来，所有里程碑都勾选也不会自动完成目标；完成目标必须由你显式选择。

当前移动端和聊天目标工具都不能编辑已有目标的标题、描述、分类或里程碑文字，也不能新增、删除单个里程碑。需要调整这些内容时，先核对原目标，再新建正确目标；确认新目标符合需要后删除旧目标。

## 删除目标 {#delete-goals}

1. 点击目标卡片中的「删除」。
2. 在「确认删除此目标？」卡片中核对目标标题。
3. 点击「确认删除目标」，或点击「取消删除目标」保留。

::: danger 不可恢复删除
删除会同时彻底删除该目标及其名下所有里程碑，无法从应用内恢复。删除目标不会删除聊天历史、工作区文件、活动、定时任务或监控。
:::

## 可见结果 {#visible-results}

- 新目标立即保存为全局目标，初始状态是「进行中」。
- 「进行中」目标从下一轮对话开始进入所有空间的模型上下文；暂停、完成或归档后不再注入。
- 里程碑勾选会影响目标卡片计数，也会改变下一轮提示中的进度和下一个未完成里程碑。
- 在目标页面直接管理目标不会自动创建聊天消息或调用模型，也不会产生模型费用；通过聊天使用 `goal` 工具仍属于模型执行，会产生模型调用费用。

## 限制与排错 {#limits-and-troubleshooting}

| 现象 | 检查 | 处理 |
| --- | --- | --- |
| 目标没有影响回答 | 目标是否为「进行中」 | 只有进行中目标注入下一轮对话；完成或归档目标不再主动注入。 |
| 想修改目标详情 | 是否已有目标 | 当前源码不支持编辑标题、描述、分类或里程碑文字；新建核对后再删除旧目标。 |
| 勾完里程碑但目标未完成 | 目标状态 | 里程碑不会自动完成目标；显式把状态改为「已完成」。 |
| 操作按钮不可用 | 列表是否旧数据、是否写入中、是否有结果未明 | 先刷新成功；结果未明时核对列表后手动解除锁定。 |
| 提交结果未明 | 页面是否显示「提交结果待核对」 | 刷新目标列表，核对创建、状态、里程碑或删除是否已生效，再解除锁定；不会自动重试。 |
| 换空间后目标仍可见 | 目标是否全局 | 这是预期行为；全局目标会作用于所有空间，删除空间不会删除目标。 |
