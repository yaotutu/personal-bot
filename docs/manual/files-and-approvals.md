# 附件、文件与审批

本页区分三类容易混淆的内容：随消息发送的附件、服务端持久保存的工作区文件，以及模型写入文件前的人工审批。操作入口和限制按当前源码核对；源码不自动等于某个已发布 APK，实际界面以你安装的 Release 为准。

## 前提 {#prerequisites}

- 手机已按[快速上手](getting-started.md#connect-mobile-client)连接真实服务端。
- 附件发送依赖 Android 系统文件选择器；当前移动端源码不支持在 Web 预览中选择附件。
- 工作区文件和审批都在当前空间的会话面板内：「聊天」页点击顶栏中间的会话信息区，再切换到「工作区」或「审批」。

## 三者如何区分 {#what-belongs-where}

| 内容 | 入口 | 归属与用途 | 关键边界 |
| --- | --- | --- | --- |
| 消息附件 | 聊天输入框左侧「+」 | 随本条用户消息进入该空间聊天历史，并作为不可信数据提供给模型 | 不是工作区文件，没有可读写的相对路径；不会自动变成长期文件 |
| 工作区文件 | 会话面板「工作区」 | 服务端持久文件；可选当前空间私有区或全部空间共享区 | 手动保存文本前必须查看完整前后全文；模型读写受工作区边界约束 |
| 模型文件审批 | 会话面板「审批」 | 模型发起的 `write` 新建/覆盖文件或 `edit` 精确编辑文件的临时授权 | 每次操作独立审批；批准只授权这一次绑定版本，不代表执行成功 |

普通文件工具只能访问当前空间私有工作区和显式 `shared/...` 共享区；没有父目录特权，不允许绝对路径、目录跳出或符号链接绕过。服务端不向模型提供 `bash`。

## 发送附件 {#send-attachments}

1. 在聊天页确认当前空间，并确认当前没有运行中的回复或待确认提交。
2. 点击输入框左侧「+」。它的读屏名称是「添加图片或文本附件」。
3. 在系统文件选择器中选择一个或多个本机文件。选择器允许请求多选；取消选择不会修改已有草稿。
4. 回到 Pi Muse 后，附件会显示在输入框上方。点击每项右侧的删除图标可在发送前移除。
5. 输入文字并点击发送箭头，或只发送附件。附件-only 消息也必须通过模型请求处理。

发送成功后，附件会随本条消息持久保存到该空间聊天历史，并在处理本条消息时发送给配置的外部模型服务。用户消息下方会显示附件名、大小和类型；图片可点击预览，文本附件只显示元数据。附件内容会标记为不可信数据，但不能保证模型完全不受其中内容影响；发送前不要包含凭据或不希望提供给该模型服务的内容，发送后继续核对模型输出和文件审批。

限制如下：

- 每条消息最多 4 个附件。
- 所有附件合计最多 8,388,608 字节；每个图片附件也不可超过该值。
- 文本附件合计最多 100,000 字节，必须非空、无 NUL 且是有效 UTF-8；图片字节必须与 PNG、JPEG、GIF 或 WebP 声明一致。
- 文件名最长 200 字符，不能包含路径分隔符或控制字符。
- 常见支持的 UTF-8 文本或源码格式包括 `txt`、Markdown、CSV、JSON、XML、YAML、JavaScript、TypeScript、Python、Go、Rust、Java、Kotlin、C/C++、C#、PHP、SQL、Shell、CSS、HTML 和 SVG；图片仅支持 PNG、JPEG、GIF 或 WebP。PDF、Word、Excel 等二进制文档不能直接解析，需先转换成受支持格式再重新选择；其他不支持的二进制会被拒绝。
- 消息文字最多 32,000 字符。图片是否会用于视觉理解取决于所配置模型的能力；配置不支持图片的模型时，不要期待可靠图片描述。

## 管理工作区文件 {#manage-workspace-files}

1. 点击顶栏会话信息区，打开当前会话面板。
2. 切换到「工作区」页。
3. 选择范围：
   - 「当前空间」：只显示和操作这个空间的私有文件。
   - 「共享文件」：显示全部空间可显式访问的共享文件；保存、编辑或删除会影响全部空间。
4. 点击目录进入，点击「上级」返回，或点击文件打开「文件详情」。
5. 文本文件会显示完整内容；PNG、JPEG、GIF、WebP 可安全预览；其他二进制文件只能「下载到设备」查看。
6. 点击「新建文本」创建文件，或打开文本文件后点击「编辑文本」修改。

手动新建和编辑只支持 UTF-8 文本，完整内容最多 100,000 字节。新建路径相对当前范围根目录，每段只能使用 ASCII 字母、数字、`.`、`-`、`_`，可用 `/` 分隔目录。当前目录超过 1,000 项或文件读取超过 8 MiB 时，服务端会拒绝而不是截断列表或内容。

### 下载到设备 {#download-to-device}

1. 在 Android 客户端打开文件详情，确认文件已经完整读取。下载复制的是这次读取到的内容，不代表之后服务端上的最新版本。
2. 点击「下载到设备」。
3. 在系统目录选择器中选择目标目录，并按系统提示确认允许 Pi Muse 访问该目录。此权限由系统选择器绑定到所选目录，不需要给应用授予“所有文件”权限。
4. 回到 Pi Muse 查看保存结果。保存成功会显示实际文件名，并确认已写入所选设备目录；取消选择目录则不会写入。

所选目录已有同名文件时，应用只提示冲突，不会覆盖旧文件。请换一个目录，或先在系统文件管理器中确认并移动、重命名既有文件。原始文件名含设备不支持字符时会改为安全 ASCII 文件名，页面会明确显示改名结果；如果目录服务强制改名或无法核对同名文件，本次下载会停止，不会猜写目标。

### 保存或删除 {#save-or-delete-files}

1. 在文本编辑器中输入或替换完整内容后，点击「预览保存」。
2. 核对「保存前 · 全文」和「保存后 · 全文」必须滚动到末尾，并确认页面顶部的范围和路径。
3. 点击「确认保存」。成功后文件详情返回服务端实际写入内容；新建遇到同名文件会失败，不会覆盖；编辑缺失文件也会失败，不会创建。
4. 删除文件时先打开文件详情，点击「删除文件」，再在确认卡片中点击「确认删除文件」。只能删除普通文件，不能删除目录。

手动保存不生成模型审批记录；它的安全确认发生在「工作区」页的完整前后全文预览中。若保存或删除请求结果未明，页面会显示「上次文件操作结果未明」，提供「回读核对」；先完整回读并核对后，再明确解除锁定。解除后再次提交会发起新请求。

普通手动保存按最后一次成功保存生效，没有自动合并或版本冲突保护。编辑共享文件前先刷新并核对当前全文；不要把模型审批的文件版本绑定机制套用到手工保存。

::: danger 不可恢复删除
删除工作区普通文件会立即移除该文件，无法从应用内恢复。共享范围的删除会影响全部空间；确认前必须核对范围和路径。
:::

## 审批模型写文件 {#approve-model-file-writes}

当前模型审批只覆盖文件写入：`write` 表示新建或完整覆盖文本文件，`edit` 表示替换现有文本中唯一匹配的一段。模型读取文件不需要审批；普通模型回复本身也没有通用人工审批。

1. 当模型请求 `write` 或 `edit` 时，会话状态显示等待审批；可点击会话信息区，进入「审批」页。
2. 点击待审批项查看详情。必须读到完整预览后才能决定；详情未同步时按钮不可用。
3. 核对：
   - 范围：当前空间私有文件或共享文件。
   - 路径和类型：新建、覆盖或精确编辑。
   - 「修改前全文」与「计划写入全文」的末尾，不能只看标题或摘要。
4. 点击「拒绝本次操作」或「批准本次操作」。
5. 在二次确认中核对提示，再点击「确认拒绝」或「确认批准」。
6. 返回审批详情查看状态和「执行回执」。已批准只表示你授权这次操作；执行可能仍因文件变化、过期、取消或写入失败而未提交。

默认等待时间为 5 分钟，从审批登记时固定，不能由客户端轮询延长。审批绑定登记时的完整内容、路径和文件版本；拒绝、过期、运行取消或等待期间文件变化都不会提交该次修改。批准不会授权其他文件、后续修改或同一路径的新版本。

若执行回执为 `unknown`，或停止/断线后不确定文件是否已写入，先在「工作区」页完整回读目标文件并与审批预览核对；不要直接批准新写入或重发请求。审批历史保留终态记录和执行回执，但历史预览不代表授权仍然有效。

## 限制与排错 {#limits-and-troubleshooting}

| 现象 | 检查 | 处理 |
| --- | --- | --- |
| 附件不能选择 | 是否在 Android 客户端；是否运行中或有待确认提交 | 等运行结束并同步；在 Android 系统选择器中选择本机文件 |
| 附件发送失败 | 数量、大小、UTF-8、图片真实格式 | 按上方限制修正后重新选择；失败附件不会进入草稿 |
| 找不到文件 | 当前范围是「当前空间」还是「共享文件」 | 先核对范围和路径，再刷新目录；读取失败不会显示为空目录 |
| 不能下载 | 是否在 Android 客户端、系统目录选择器是否取消或拒绝访问 | 当前 Web 预览不支持保存到设备目录；在 Android 上重新选择目录并按系统提示允许访问 |
| 提示同名文件冲突 | 所选设备目录中是否已有同名文件 | 应用不会覆盖；换目录，或先在系统文件管理器中确认并移动、重命名旧文件 |
| 手动保存失败 | 是否超过 100,000 字节、路径非法、新建同名、编辑缺失 | 修正内容或路径；新建换路径，编辑先刷新现状 |
| 审批按钮不可用 | 审批状态是否待同步、是否已过期、详情是否未读取 | 点「重新同步审批」并重新打开详情；过期后需要模型重新发起 |
| 批准后文件未变 | 执行回执是否成功、期间文件是否变化 | 先完整回读文件；不要重复批准旧审批 |
