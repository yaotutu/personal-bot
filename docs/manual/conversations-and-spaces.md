# 对话与空间

本页说明手机客户端中的日常聊天、空间切换、停止运行、会话重置和空间删除。操作入口按当前移动端与服务端源码核对；源码不自动等于某个已发布 APK，实际界面以你安装的 Release 为准。

## 前提 {#prerequisites}

- 已按[快速上手](getting-started.md#connect-mobile-client)连接服务端，顶部连接状态为「已连接」。
- 已配置可用的外部模型；模型未配置时，聊天消息会被拒绝。
- 已区分「空间侧栏」和「会话面板」：左上角菜单打开的是空间侧栏；点击顶栏中间头像、名称和状态打开的是当前会话面板。

## 发送与停止对话 {#send-and-stop-conversations}

1. 在底部「聊天」页确认当前空间。若要换空间，先按「管理空间」操作。
2. 在「消息」输入框输入文字。需要随本条消息发送图片或文本时，点击[附件说明](files-and-approvals.md#send-attachments)中的「+」按钮。
3. 点击输入框右侧发送箭头。可见成功标志是你的消息进入聊天列表，顶部状态变为执行中。
4. 回复流式显示；模型调用工具时，消息中的工具卡或会话面板「动态」页会显示执行进展。
5. 需要停止时，点击同一个右侧按钮。运行中它显示为停止方块；等待状态同步时按钮不可用，先点「重新同步」。

停止成功后，本轮流状态会变为已停止或结束。停止、切换空间导致聊天视图卸载、断开聊天流或服务重启时，当前聊天运行会被取消，未决文件审批也会作废；但已经完成的工具操作不会回滚。

一个空间同一时间只允许一个聊天运行。发送状态未明或历史版本未同步时，客户端会锁住发送按钮；先点「重新同步」并核对权威历史，不要通过反复杀进程或重发绕过锁定。

## 管理空间 {#manage-spaces}

1. 点击聊天页左上角菜单，打开「你的空间」侧栏。
2. 点击任意空间即切换；当前空间带选中标识，聊天页会随之切换历史、草稿和运行状态。
3. 在底部「搜索空间」框中输入空间 ID 可过滤列表。
4. 点击右下角「新建空间」图标。客户端会生成一个 `side-` 开头的空间 ID 并立即切换到它。
5. 在新空间发送第一条消息，或打开会话面板保存空间规则/技能，使它在服务端真正建立。只点击「新建空间」而没有写操作时，它只是手机上的本地空条目，之后可能从服务端列表消失。

空间 ID 由字母开头，只含字母、数字、`_`、`-`，最长 64 字符。当前手机源码不提供重命名入口；若需要另一个名称，请新建并迁移需要的内容。

每个空间拥有独立会话历史、私有工作区、空间规则和技能开关。助手与用户资料、长期记忆是全局内容，不随空间隔离。

## 空间规则与技能 {#space-rules-and-skills}

1. 点击顶栏中间的会话信息区，打开当前会话面板。
2. 切换到「工作区」页。
3. 在「空间规则」中填写你希望助手在本空间遵守的方式，点击「保存规则」。成功后读取值更新；规则从下一轮对话开始生效，不修改已生成历史。
4. 在「空间技能」中切换技能开关并点击「保存技能」。开关只影响当前空间。

空间规则最多 20,000 字符。关闭面板不会丢弃当前连接内未保存草稿；换服务器或清理本机缓存会丢弃本地草稿。

## 重置与删除空间 {#reset-and-delete-spaces}

### 重置当前会话 {#reset-current-session}

1. 进入底部「设置」→「会话维护」→「重置当前会话」。
2. 核对对话框中的目标空间。
3. 默认重置会停止当前运行，清空该空间聊天历史、消息反馈、未完成审批、Dream 整理游标与待决建议，并开启全新会话；空间规则、技能开关、Dream 配置和私有工作区文件会保留。
4. 如需同时删除该空间绑定的定时任务与网页监控，勾选「同时清理此空间下的定时任务与网页监控」。默认不勾选，任务和监控会转绑到新会话。
5. 点击「确认重置」。成功后显示「会话已重置」，可开启全新对话。

被清空的聊天历史和消息反馈无法恢复。若网络结果未明，客户端会显示待确认并暂停发送；先点击「核对重置结果」，不要自动重试重置。

### 删除空间 {#delete-space}

1. 在空间侧栏切到要删除的非主空间。
2. 点击顶栏会话信息区，打开会话面板的「工作区」页。
3. 滚动到「删除当前空间」，点击进入确认卡片。
4. 核对删除范围后点击「确认删除」。

::: danger 不可恢复删除
删除空间会彻底清除该空间的聊天历史、消息反馈、私有工作区文件、空间规则、技能配置、Dream 配置与整理状态，以及绑定的定时任务和网页监控。操作不可撤销，不会自动迁移到主空间。主空间不可删除；只想清空对话时使用「重置当前会话」。
:::

删除请求结果未明时，先刷新空间列表核对，不要重发删除请求。删除成功后，之后使用相同 ID 新建空间也不会恢复旧历史。
