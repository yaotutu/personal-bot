# 核心能力

## 对话与空间 {#conversations-and-spaces}

在移动客户端连接服务端后，可创建和切换空间，每个空间使用独立会话与指令。聊天支持流式回复、工具执行状态和历史记录；文件附件与图片由客户端发送，图片理解取决于所配置模型的能力。

## 任务、目标与记忆 {#tasks-goals-and-memory}

可在对话中提出一次性或每日定时任务、网页监控和长期目标，再到客户端对应页面查看与管理。网页监控面向公开 HTTP(S) 页面。长期记忆可按需检索；可选的 Dream 周期整理需要单独启用。任务失败会显示错误，不会自动重跑模型或工具。

## 文件与审批 {#files-and-approvals}

普通文件工具仅能访问当前会话私有工作区及显式的 `shared/...` 共享区。模型发起的每次 `write` 或 `edit` 都要人工查看完整修改预览并批准；拒绝、过期、文件变化或运行取消不会提交该次修改。服务端不向模型提供 `bash`。

## 浏览器 {#browser}

服务端提供真实图形浏览器能力，启用与访问范围由配置控制。Docker 与 noVNC 的部署和人工接管步骤见[浏览器说明](browser-docker.md)；移动客户端内的具体浏览器集成能力请以对应发布版本为准。

## 数据与网络 {#data-and-network}

服务端实例目录保存明文会话、记忆和凭据，请保护目录及备份权限。模型请求会把当前任务所需内容发送给配置的外部模型服务。HTTP 可用于连接，但不会加密 AccessKey、Token 或对话内容；远程访问时应评估网络环境。更多设置见[配置说明](configuration.md)。
