# 本轮：初始化 pagent-mobile 工程 + 交接文档

## 1. 脚手架（~/Desktop/code/pagent-mobile，独立 git 仓库）

- `create-expo-app`（blank-typescript 模板，最新稳定 SDK），TypeScript strict。
- Web 支持：`expo install react-dom react-native-web`；Expo Web dev 端口 8082（避开 openmuse 8081）。
- 依赖一次装齐：`lucide-react-native` + `react-native-svg`、`react-native-markdown-display`、`zod`（全用 `npx expo install` 保版本兼容；SSE 用 SDK 内置 `expo/fetch`）。
- `app.json`：应用显示名 **Pagent**。

## 2. 地基文件

- `src/ui/tokens.ts`：OpenMuse 设计 token 落地——颜色（canvas #FCFCFC / card #FFF / ink #11191C / muted #697176 / line #EEEEF0 / bubble-user #C8E7FF / accent #1473C8 / sky #EDF7FD / success-bg #E3F3E8 / success #47896C / lavender #F0EEFA / waiting #FDF0DF / danger #AA4A45 配 #FBEFED / subtle #F1F2F3）、圆角（card 23 / sheet 26 / bubble 22 尾角 7 / pill 32 / tab 40 / button 24 / field 19 / iconbox 13）、字号阶梯（text 15/23、muted 14/21、label 10 大写 1.4 字距、title 23/-0.7）。
- `App.tsx`：极简占位屏（canvas 底色 + "Pagent"），验证工程与 token 生效即止，不做功能。
- 目录骨架：`src/{lib,ui,chat,activity,goals,apps}`。
- `AGENTS.md`（协同红线：personal-bot 严格只读、接口事实来源=服务端 API 文档页、不合理接口停下喊用户、不用 CopilotKit、技术决策定稿）。
- `README.md`（启动命令：mock 后端 8788 + Expo Web 8082）。
- `docs/HANDOFF.md`：交接文档落盘（与给你的纯文本一致）。

## 3. 验证

- `tsc --noEmit` 通过。
- `npx expo export`（或起 `expo start --web --port 8082`）确认 web 产物可渲染（浏览器打开占位屏）。

## 4. 提交与交付

- `git init` + 首次 commit（仅 pagent-mobile 仓库，不触碰 personal-bot）。
- 回复中附**纯文本交接文档**：项目定位、协同协议、已完成/未完成、技术决策定稿（SSE 用 expo/fetch 翻译 web/src/lib/api.ts、工具卡 Map 注册+通配、4 tab 结构、聊天页视觉规格）、下一步顺序（组件原语→登录门→聊天主链路→工作台三页→Android 模拟器 smoke→真实验收）、验收方式；末尾附服务端 agent 视角的协同说明（API 文档页需求、SSE 事件类型补契约建议）备用。
